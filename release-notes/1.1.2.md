## What's new in 1.1.2

### New
- **Control from other programs**: the new `gremlin-ctl.exe` command line reads and controls Gremlin-Platforms while it runs. Off until you turn on **Allow control from other programs** in Options › General
- **Screen Saver Mode › Devices**: a new tab with a remembered device list. Set each device to **Automatic** (switched off while the displays are off) or **Manual** (left alone). Earlier **Switch off** choices aren't carried over
- **Auto-load**: choose what happens when a program with no profile comes to the front: **Stop the profile**, **Keep running** or **Load the default profile**
- **Scripts** can switch modes: `switch_mode`, `previous_mode` and `cycle_modes`

### Changed
- **Options** holds the open profile's settings under **This profile**: **Startup and macros**, **vJoy** and **Scripts**. Their separate toolbar buttons are gone
- **Merge Axis**: **Prefer Center** is now **Closest to Center**. A 1.1.1 profile that uses **Prefer Center** doesn't open in 1.1.2: pick another operation before you update
- **Keep vJoy devices awake** (Options › General) is now a switch, off by default. Turn it on only if an older vJoy version needs it
- **Reference**'s list shows where each action is (mode, device and input)
- Scripts that name the event type use `gremlin.types.Event` (was `gremlin.event_handler.Event`)
- Less memory growth as you change pages and open windows, and a smaller install

### Fixed
- Held keys, buttons and macros stayed on when the mode changed before you let go
- **Map to Keyboard** waited behind an exclusive macro
- **Macro**: a repeat delay didn't end when you let go, a second tap didn't cancel a waiting Toggle macro, and other macros could run during an exclusive one
- **Condition**: a release could leave an output held, and a check on an unplugged stick didn't count as false
- F13 to F24 were sent and recorded as other keys
- Moving an action into its own children could lose it
- The Logical Device lists in Search, Health and Scripts offered inputs of the wrong type
- **Screen Saver Mode**: the running profile restarted when devices were switched off and back on
- **Screen Saver Mode**: a switched-off device could stay off after you plugged it back in, and **Last time away** could show wrong counts
- **Screen Saver Mode**: vJoy turned the displays back on about once a minute while a profile ran
- **Search** and **Health**: columns line up with their headings, and Health's window stays wide enough
