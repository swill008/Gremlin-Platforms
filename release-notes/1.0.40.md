## What's new in 1.0.40

### New
- **Controls keep working while the window is busy or "Not responding".** Your sticks, buttons, macros and timers (Tempo, Double Tap, Smart Toggle, pulses) now run on their own thread, separate from the window. If Windows freezes the window (for example when the screens turn off and on), your bindings keep sending to vJoy
  - While a profile is starting, the status shows **Starting** until it is running
  - A change you make to the profile while it runs applies the next time you press Run
- **Window trace and Timing trace** (Tools › Live Log Reader…, Trace tab). Two new rows:
  - **Window** records the main window's tray, page, screen and display-power steps, so a blank or missing window can be explained afterwards. The last 200 window events are always kept in memory, and **Debug › Save Window State** writes them to a file (they are also in Save Diagnostics)
  - **Timing** writes a summary every 10 seconds of how long your inputs take inside the program: from the driver, waiting behind earlier inputs, the hand-over between threads, the actions, and from start to end

- **What's New after an update.** When Gremlin-Platforms starts on a newer version, a blue bar under the toolbar says **Updated — now <version>**. Click **What's New** to read what changed, or ✕ to close the bar. You can read the notes any time from **Help › What's New…**. The notes come with the program, so no internet is needed

### Changed
- The separate "Updated" notice after an update is gone; the blue bar replaces it
- **The first input after a profile starts no longer waits for vJoy.** The vJoy devices your profile uses are opened while the profile starts, instead of on your first stick movement (that first movement used to arrive 20-140 ms late)
- **Tool windows open on the main window's screen the first time.** A tool window that has no saved place yet, or whose screen is gone, opens on the same screen as the main window; after that it opens where you left it

### Fixed
- The main window could come back **blank** (black page area) after it had been hidden to the tray, until you chose **Show Gremlin-Platforms** in the tray
- If the program failed while starting, or took too long to close, it could be left running with no window and stop the next start; it now always ends
- Timing summaries no longer show impossible waits or empty lines, and a wait caused by a profile restart says so
