## What's new in 1.0.40

### New
- **Controls keep working while the window is busy or "Not responding".** Your sticks, buttons, macros and timers (Tempo, Double Tap, Smart Toggle, pulses) now run on their own thread, separate from the window. If Windows freezes the window (for example when the screens turn off and on), your bindings keep sending to vJoy
  - While a profile is starting, the status shows **Starting** until it is running
  - A change you make to the profile while it runs applies the next time you press Run
- **Window trace and Timing trace** (Tools › Live Log Reader…, Trace tab). Two new rows:
  - **Window** records the main window's tray, page, screen and display-power steps, so a blank or missing window can be explained afterwards. The last 200 window events are always kept in memory, and **Debug › Save Window State** writes them to a file (they are also in Save Diagnostics)
  - **Timing** writes a summary every 10 seconds of how long your inputs take inside the program: from the driver, waiting behind earlier inputs, the hand-over between threads, the actions, and from start to end
- **What's New after an update.** When Gremlin-Platforms starts on a newer version, a gold bar under the toolbar says **Updated to <version>**. Click **What's New** to read what changed, or ✕ to close the bar. You can read the notes any time from **Help › What's New…**. The notes come with the program, so no internet is needed
- **Screen Saver Mode: choose which devices are switched off.** Each row of the Devices list (Tools › Screen Saver Mode…) has a **Switch off** switch. Turn it off for a device you want left alone while the displays are off, for example a stick you are using. New devices start switched on
- **Screen Saver Mode: Test now.** A **Test now** button (Tools › Screen Saver Mode…) runs the whole sequence after a 5-second countdown: devices switched off, displays off, kept off until you move the mouse. No need to shorten the timers to try it
- **Screen Saver Mode in the tray.** Right-click the tray icon: **Screen Saver Mode** turns it on or off, **Turn displays off now** turns the displays off straight away
- **Screen Saver Mode: Wait for devices to switch off** (under Timers, 1-60 s, 10 s at first): how long the displays wait at most for the devices to switch off
- **Screen Saver Mode: a clearer Status.** Status is now a two-column table and adds **Last time away** (for example "Displays off 12 min 46 s · 1 wake-up · 2 devices switched off and back on · no freeze") and **Devices back on** (with **Try again** if a device didn't come back on)
- **Keep tracing on after a restart** (Live Log Reader › Trace): tracing and its ticked rows come back on by themselves after a restart or an update. While tracing, a **State** block lists your current settings, and Save Diagnostics adds it as state.txt
- **Better freeze reports.** With **Log When Not Responding** on, a freeze report now also says what Windows reports the window is waiting on, and a profile start that takes 300 ms or more writes which steps were slow

### Changed
- The separate "Updated" notice after an update is gone; the gold bar replaces it
- **History keeps to configuration.** Screen Saver Mode's settings, Diagnostic logs and Log When Not Responding are still saved, but no longer listed in Tools › History
- Screen Saver Mode no longer holds off when Gremlin-Platforms' own window is full screen
- Screen Saver Mode's "Windows turned the displays back on" hint now shows only after 3 or more wake-ups
- **The first input after a profile starts no longer waits for vJoy.** The vJoy devices your profile uses are opened while the profile starts, instead of on your first stick movement (that first movement used to arrive 20-140 ms late)
- **Tool windows open on the main window's screen the first time.** A tool window that has no saved place yet, or whose screen is gone, opens on the same screen as the main window; after that it opens where you left it

### Fixed
- The main window could come back **blank** (black page area) after it had been hidden to the tray, until you chose **Show Gremlin-Platforms** in the tray
- If the program failed while starting, or took too long to close, it could be left running with no window and stop the next start; it now always ends
- Timing summaries no longer show impossible waits or empty lines, and a wait caused by a profile restart says so
- Screen Saver Mode: the program could stop responding for seconds to minutes while the displays were off, as Windows kept waking them. Screen Saver Mode now switches the noisy devices off first and turns the displays off when they are done (a second or so later), so the displays stay off and the program stays responsive. Turning the displays off again after a wake-up no longer depends on the program's window
- Screen Saver Mode never switches off vJoy or Gremlin's own Xbox pad, even if Refresh Devices lists them (it could list them while a profile was running)
