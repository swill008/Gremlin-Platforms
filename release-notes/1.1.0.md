## What's new in 1.1.0

### New
- **What's New** is displayed after an update; click What's New to read the notes. Also can be reviewed in the Help › What's New…
- **Screen Saver Mode** (Tools › Screen Saver Mode…):
  - **Switch off per device**: choose which devices are switched off while the displays are off.
  - A clearer **Status**, including **Last time away** and **Devices back on**
  - In the tray menu: **Screen Saver Mode** on/off and **Turn displays off now**
- **Tracing**: a Window row and a Timing row, and **Keep tracing on after a restart**

### Changed
- The program is now Release Candidate 2; **Gremlin-Platforms R2**
- **Device Maps** still in the old photo layout are converted once at start; a backup is kept and the pictures stay the same
- The first input after a profile starts no longer waits for vJoy to open
- **Tool windows** open on the main window's screen the first time

### Fixed
- The window could stop responding for a long time while **Screen Saver Mode** kept the displays off. Devices are now switched off first, then the displays
- The main window could come back blank after being hidden to the tray
- The program could stay running with no window after a failed start or a slow close
