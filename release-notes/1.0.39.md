## What's new in 1.0.39

### New
- **Wake PC** (Tools › Screen Saver Mode…, new **Wake PC** tab). Choose which keyboards and mice can wake the PC: only ticked devices reset Screen Saver Mode's idle time, so a game controller or other device that also acts as a mouse or keyboard (for example a Steam Controller) no longer keeps the screens awake
  - Every keyboard and mouse Windows reports is listed once per device, with its keyboard and mouse parts together
  - Everything starts unticked. With the tab open, press a key or click a mouse button and that device ticks itself; you can also tick or untick by hand, and a device you untick stays unticked
  - With the tab open, a device's row lights up with **in use now** for a couple of seconds whenever you use it, so you can see which row is which device
  - Keys and mouse movement sent by other programs (for example RustDesk or remote desktop) always count
  - While Screen Saver Mode is on and nothing is ticked, neither timer runs and the window says **Waiting: tick at least one keyboard or mouse on Wake PC.**
- **The installer closes Gremlin-Platforms for you.** When you install an update while Gremlin-Platforms is running, even hidden in the tray, the installer asks it to close the way File › Exit does (it asks you about unsaved changes if there are any), waits 10 seconds, installs, and starts it again

### Fixed
- Screen Saver Mode: with a second display (for example a TV), the screen saver no longer stops **Power off displays** from happening
- Screen Saver Mode: closing Gremlin-Platforms while the device helper was running could hang the program
- Screen Saver Mode: if Windows answers that disabling a device needs a restart, the device is switched back on at once, and devices waiting for a restart are always switched back on, so nothing is left disabled after a restart
