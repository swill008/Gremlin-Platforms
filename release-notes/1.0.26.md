## What's new in 1.0.26

### New
- **History** highlights what changed
  - Changed lines tinted (red Before, green After) and changed words marked
  - Previous / Next Change buttons
- **Help › Save Diagnostics…** (also on the Debug tab)
  - One zip with logs, settings, device list and versions, to send with a problem report
  - Your user name is replaced by `<user>`; the open profile only if you tick it
- **Release notes in Check for Updates**: what changed in the new version, and in any you skipped
- **Auto Mapper** says which mode the actions went into
  - Select Mode starts on the toolbar's mode
  - A note when that isn't the mode you're viewing, and the reason when nothing is made

### Changed
- vJoy is put at rest (buttons up, axes and hats centred) when Stop or quit lets it go
- An unplugged stick's axes read as centre in every action
- Button Map and Device Pack exports run in the background ("Exporting…")
- Adding a script or loading a profile doesn't wait for the script to start
- Help explains that an axis not moved since start is sent as centre at Run: nudge throttles and brakes after pressing Run

### Fixed
- Map to vJoy Relative moves the axis even when nothing else writes to that vJoy
- The vJoy keep-alive re-sends after 60 s, not ~120 s
- Swap Bindings: the question is no longer cut off, and Esc cancels it
- Device Information no longer lists vJoy and this program's Xbox pad
- Calibration opened for an unplugged stick waits for it
- Highlighting stays off while Calibration is open, through Run/Stop, Listen and macro Record
- Module Setup for another device opens after Save or Discard; File › New asks about open panels first
- An unplugged stick's Configuration page moves cleanly to the next device
- Button Map labels refresh after action edits; template export/rename failures say why
- "Off: never runs" shows at once; cards without a module file show their counts
- The Diagnostic logs level is kept in History
- Action images follow the UI scale; Options labels wrap; Merge Axis and History headings fit
- Device Pack opens on a device that can be exported; the Auto Mapper keeps its ticks after Create
- OSC host and port boxes save when Options closes; the Live Log button reads "Copy All"
- Large profiles no longer stutter every 1.5 s
