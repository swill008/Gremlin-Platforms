## What's new in 1.0.30

### New
- **Device Library**: keep, copy and swap stick setups
  - Save a stick's setup, copy it to another stick, swap two sticks, or change which vJoy device a stick sends to
  - An autosave is kept before anything replaces or removes a stick's settings (the newest 10 per stick)
  - Undo and Redo in Edit (Ctrl+Z, Ctrl+Y) and in every right-click menu; the status bar shows the last change
  - Right-click menus, the Delete key, and Show in History for a device or saved setup
  - Keyboard and OSC are listed under their own Built-in inputs heading
- **One Help**: all help is now one book with a chapter per part of the program
  - Help (F1) in the Button Map or the Device Library opens just that chapter; View Full Help shows everything
  - Search Help (Ctrl+F): matches are highlighted, with F3 and Shift+F3 to move between them
  - Every topic was rewritten to be clearer and easier to follow
- **Clear History** in Tools › History removes all saved changes after a clear warning, and leaves a red "History cleared" line as a record
- Every Device Library change is now in Tools › History and can be restored there

### Changed
- The Mode box and Manage Modes moved to a bar under the toolbar, on every page
- A profile opens in the mode you last ran it in (Startup Mode "Last Active"); "Use Heuristic" is gone
- Text boxes: press Esc or click anywhere outside a box to leave it; what you typed is kept
- Renaming works the same everywhere: the name opens selected, Enter or a click away saves, Esc cancels
- Tooltips appear after the same short delay everywhere and wrap long text
- Options opens much faster
- Each Button Map action is now exactly one undo step

### Fixed
- A device whose old ids still pointed at its module file can now be removed from the Device Library
- Ctrl+Y works in Calibration and Module Setup, and Ctrl+Shift+Z on the Logical Device page and in the Binding catalog
- The Binding catalog's Redo now comes on after an Undo
- A text box that only saved on Enter now also saves when you click away
