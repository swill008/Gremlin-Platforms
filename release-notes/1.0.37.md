## What's new in 1.0.37

### New
- **Holding Esc to stop recording keeps what you had.** Holding Esc on "Waiting for user input" now cancels the recording and leaves the input that was set before untouched. This covers Map to Mouse, Map to Keyboard, the Macro joystick, key and mouse-button steps, the joystick and keyboard Conditions, and the key and joystick settings of scripts. Before, Map to Mouse and the script settings closed the program with an error, and Map to Keyboard, Macro and Condition cleared what was recorded
