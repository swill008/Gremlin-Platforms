## What's new in 1.0.27

### New
- **Search layers** in the Button Map's Layers panel (in Edit)
  - Type to filter by name, control (Button 12, Hat 1, even when renamed), what a chip shows (e.g. "Fire") or kind
  - One toggle per kind (Chips, Groups, Hotspots, Leaders, Shapes, Lines, Pictures, Text, Tables, Photo); All clears them
  - Matches inside a chip or group show under it; a count line says how many match
  - Ctrl+F or View › Search layers… to search, Esc clears, Enter selects every match
  - Your choices stay while the Button Map is open and reset when it closes

### Fixed
- The Button Map's Command Palette (Ctrl+K) runs the command you pick even when it isn't pinned
- View › Properties is offered only in Edit, where it works
