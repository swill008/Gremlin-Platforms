## What's new in 1.0.38

### New
- **Screen Saver Mode** (Tools › Screen Saver Mode…). Some devices, such as flight sticks and throttles and some USB microphones, send reports to Windows many times a second even when nobody touches them. Windows counts that as someone using the PC, so the screen saver and display-off never happen, a burn-in risk on OLED screens. Screen Saver Mode keeps its own idle time from your keyboard and mouse only, and when it runs out it starts the screen saver or powers off the displays, whichever you choose
  - Off until you switch it on; it remembers
  - **Wait time** shows Windows' own time and follows it when you change it in Windows; type your own time to use that instead, clear it to go back to Windows'
  - Holds off while a full-screen program is in front (can be switched off), while a program such as a video player keeps the display on, and while the PC is locked
  - Keys and mouse movement sent by other programs (for example remote control) count; keys and mouse input sent by Gremlin-Platforms' own bindings don't
  - **Refresh Devices** lists the devices that never go quiet and keep Windows awake
  - **Refresh Programs** lists the programs, drivers and services asking Windows to keep the display or the PC on, each with an **Ignore this program** switch (both ask for administrator rights)
  - Works only while Gremlin-Platforms is open
  - For problem reports: a **Screen Saver Mode** tick on Debug › Tracing records the countdown, holds, each scan and the exact Windows commands and answers; errors always go to the log
