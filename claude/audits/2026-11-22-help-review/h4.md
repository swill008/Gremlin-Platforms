## Top 5 problems

1. **Drivers page is out of order and partly wrong.** The vJoy-update box comes
   before you know how Apply works. The three questions Apply can ask (Run stops,
   in use, can't be told apart) are scattered over two lists. And the tick boxes
   are called **Slider 1 / Slider 2**, but the approved short names are **S1 / S2**
   (glossary row 38, D-AXIS-NAMES).
2. **Walls of text.** Many single bullets or paragraphs run 80 to 150 words and
   hold several ideas: the Drivers Custom bullet (152), the Window trace row (540),
   the Screen Saver Mode status table (420), the Input Tester Logs tab (208) and
   rows (225), and the Search tags (351).
3. **Stale or broken facts.** How HidHide decides names HidHide **1.4.181**, but the
   program carries 1.5.230. The `USB\VID_…` example loses its backslash in
   JavaScript, so the screen shows "USBVID_0DB0". Wake PC says the devices that
   never go quiet "are still disabled", but only the ones marked **Switch off** are.
4. **Test notes and internal words in user Help.** "it was checked on an LG OLED",
   "Windows gave this answer for an Xbox One controller", "cloak", "state
   snapshot", "Gremlin's own Xbox pad", "Setup starts it the same way", and
   statistics terms in Timing.
5. **Repetition.** The Logical Device restore rule is said twice in a row
   (306-307). "Set HidHide up first, then start the game" is repeated in the
   HidHide page, the Input Tester page, the technical table and the Common
   question. "Not while flying." appears three times as a bare fragment.
