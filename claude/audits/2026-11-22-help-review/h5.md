# Help review H5: qml/help/osc.js (OSC chapter)

Reviewer H5, 2026-11-22, read-only. File reviewed: `qml/help/osc.js` (852 lines, 33 topics),
checked against `claude/glossary.md` and `claude/program-map/09-osc-sound-misc.md`.
`DialogHelp.qml` shows this text as Qt rich text, so `<h4>`, `<ul>`, `<ol>`, `<table>` and `<code>`
all display.

Counts: high 6, medium 33, low 20.

## Top 5 problems

1. **Help contradicts itself on when the port is open (high).** Server tab, Network reference and
   Good to know say the port is open whenever **Listen for OSC messages** is on (S172a,
   D-09-OSC-ALWAYS-LISTEN). The OSC Monitor topic (489), Macros (598) and the troubleshooting page
   (642) still describe the older rule, where the Monitor, Record or Run open and free the port.
2. **The Companion how-to is in the wrong order (high).** Step 1 uses **Copy for Companion** on an
   input, but the input is not added until step 4.
3. **Too many names for one window (medium, but it confuses newcomers).** The same window is called
   "OSC Setup…", "OSC's Module Setup", "Input Module Setup", "OSC › Module Setup" and
   "Open OSC Module Setup" (lines 70, 94, 122, 126, 257). Help should pick one name for sentences
   (glossary: OSC's **Module Setup**, opened with **OSC Setup…**) and give the window's title once.
4. **Dense bullets that are walls of text (medium).** Many bullets run to 40-90 words and pack 3-5
   ideas, for example 146, 152, 167, 187, 225, 245, 306, 307, 431, 443 and 448. These are the hardest
   parts of the chapter to read.
5. **Repetition and filler (medium/low).** The port-open rule appears 6 times (68, 142, 151, 618, 681,
   816). Save/Discard/History appears twice (131-132, 814-815). "unless you change it" or
   "On unless you turn it off" appears about 30 times. Writing "(default 8001)" or
   "On by default." instead would cut a lot of words.

- **147, medium (unclear how it combines with 146).** After: "**Pad address-only messages**: treats
