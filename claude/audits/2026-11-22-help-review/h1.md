# Help review H1: Getting started, Modes, index (2026-11-22)

Reviewer: agent H1 (read-only). Files: `qml/help/getting_started.js`,
`qml/help/modes.js`, `qml/help/index.js`. Rendered by `qml/DialogHelp.qml`
as Qt RichText (`<p>`, `<ul>`, `<ol>`, `<h4>`, `<b>`, `<i>`, `<code>` all
render; Qt RichText also renders simple `<table>`, which could help a few
topics below). Checked against `claude/glossary.md` and, lightly,
`claude/program-map/01-app-shell.md`.

Severity: **high** = confusing or wrong; **medium** = hard to read;
**low** = polish.

## Top 5 problems

1. **"Install and update the program" is a wall.** One topic of about 1,100
   words covers downloads, setup's Drivers page, vJoy device rows, checksums,
   VC++ runtime, HidHide restarts and Check for Updates. Bullet at line 71 is
   about 200 words with nested brackets. Split it into three topics
   (Install, Setup's Drivers page, Check for updates) and use short bullets.
2. **Wrong or self-contradicting facts.** "three separate stores" lists four
   (line 241); "the program says "Updated" once" (line 90) clashes with the
   "Updated to <version>" bar (line 92) and with the glossary, which bans
   bare "Updated"; the axis tick boxes are named **Slider 1/Slider 2**
   (line 71) where the glossary says the tick boxes read **S1/S2**.
3. **Mode switching is explained by name only.** `modes.js` line 120 lists
   Switch/Previous/Unwind/Cycle/Temporary in one sentence; Previous vs Unwind
   is not told apart, and line 122's **Oldest**/**Newest** never says what
   each does. A reader can't choose from this text.
4. **Layout descriptions instead of tasks.** Several topics describe where
   things sit (Drivers page rows, toolbar left to right, menu behaviour) in
   long run-on bullets, rather than "to do X, do Y". The toolbar bullet
   (line 50) is ~130 words with nine links in one line.
5. **Compressed shorthand and undefined terms.** "Forget It (off Recent and
   start-up; the file stays)", "Once you save a keyboard choice",
   "Windows you use a stick in ignore Esc", "mode history", "the list of
   parents", "Before the update setup says it has noted your devices (OK)".
