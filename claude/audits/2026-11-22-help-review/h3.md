# Help review H3: qml/help/device_bindings_actions.js

Reviewer H3, 2026-11-22, read-only. The file is shown in `qml/DialogHelp.qml`
as Qt RichText, so `<h4>`, `<ul>/<ol>`, `<table>`, `<b>` and links all
render. Line numbers are for the file as it is today (776 lines).

Severity: **high** = confusing or wrong, **medium** = hard to read,
**low** = polish.

## Top 5 problems

1. **Wall-of-text bullets and paragraphs.** Several bullets hold 4-6 ideas
   (`:34` Bindings, `:250` Delete Key, `:283`-`:284` Appearance, `:684` Send
   OSC values, `:765` red ⚠ answer). They need splitting into one idea per
   bullet, or a small sub-list.
2. **Unexplained terms.** "fires", "container actions", "instance",
   "pulses", "latches", "Unwind", "Pre-Emptive", "Mode cycle resolution",
   "wire", "the hidden action that holds an input's actions". A reader can't
   tell what these mean or do.
3. **Garbled sentences** in Merge Axis and Dual Axis Deadzone (`:495`-`:496`,
   `:514`-`:515`): "those other inputs use" and "Picking one another input
   uses shares it". You have to read them twice to find the meaning.
4. **Choices listed without saying what they do.** Change Mode (`:609`-`:613`:
   Previous vs Unwind), Macro (`:444`-`:445`: Repeat Mode and Exclusive vs
   Pre-Emptive), Double Tap (`:564`-`:565`), Response Curve types (`:463`).
5. **Words that disagree with the glossary or with the rest of the file.**
   "the first box" for the type box **All inputs** (`:95`); the
   **Delete actions…** button **Delete Actions** isn't named (`:82`);
   "Invert activation" reads as required on Map to vJoy (`:354`); the
   Options path is written in a different style at `:744`.
